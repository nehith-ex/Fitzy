# Fitzy

Fitzy is an all-in-one fitness app that brings workouts, nutrition, habits and progress into one place, with a customisable calendar and an AI coach that knows your training history.

## Features
- Workout logging with sets, reps and weight
- Customisable calendar (month/week views, colours, tracked metrics)
- Dashboard with quick access to food, workout and habit tracking
- Floating AI coach chat
- Progress tracking and personal records (planned)

## Tech stack
React, TypeScript, Vite, Supabase (Postgres, Auth, Row Level Security)

## Setup
1. Clone the repo and run `cd web && npm install`
2. Create `web/.env` with `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY`
3. Run `npm run dev`
